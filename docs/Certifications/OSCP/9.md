# Linux 提权

## 查看用户信息

```bash
w
id
whoami
cat /etc/passwd
```

## 系统版本信息

```bash
cat /etc/os-release
内核
uname -a
```

## 进程信息

```bash
ps aux
ps -efw
```

## 网络连接

```bash
ip a
ifconfig
ip route
ss -partu
```

## 计划任务

```bash
grep -ro Ri /etc/cron*
grep -RE 'passwords?=".*"' 2>/dev/null
grep -E '\w*([0-9]|[0-9][0-9])\w*' /etc/cron*
/etc/crontab
crontab -l
ls /var/spool/cron
cat /var/log/cron.log
```

查看实时进程

```bash
pspy
```

## 可写的目录

```bash
find / -writable -type d 2>/dev/null
```

## 系统分区

```bash
/etc/fstab
```

## SUID 程序枚举

```bash
find / -perm -u=s -type f 2>/dev/null
```

## 环境变量

```bash
env
env -spilt-string-touch /tmp/yfh
cat .bashrc
cat .bash_history
```

## sudo 权限

```bash
sudo -l
```
