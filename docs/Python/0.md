## 1.1 内置函数

```python
# 列举python内置函数
dir(__builtins__)

# 数字的四舍五入 round()
语法：round(number,digits)
digits>0，四舍五入到指定的小数位
digits=0, 四舍五入到最接近的整数
digits<0 ，在小数点左侧进行四舍五入
如果round()函数只有number这个参数，等同于digits=0
```

## 2.1 比较运算符

| 运算符 | 含义                         |
| ------ | ---------------------------- |
| <      | 判断左边是否小于右边         |
| <=     | 判断左边是否小于等于右边     |
| >      | 判断左边是否大于右边         |
| >=     | 判断左边是否大于等于右边     |
| ==     | 判断左右两边是否相等         |
| !=     | 判断左右两边是否不相等       |
| is     | 判断两个对象的 id 是否相等   |
| is not | 判断两个对象的 id 是否不相等 |
